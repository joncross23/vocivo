# Vocivo Visual System

This document turns the product mood into a usable visual language. It is not a final design file, but it should keep the build from drifting into generic learning-app UI.

## Core direction

Vocivo should feel like:

- a learner's command deck
- a night-drive revision machine
- a product with some tension and attitude, not a soft productivity toy

The visual identity should combine:

- instrument-panel clarity
- editorial confidence
- arcade energy

It should not feel like:

- a school LMS
- a cheerful primary-school app
- a default SaaS dashboard with flashcards added

## Visual pillars

### 1. Velocity

The interface should imply motion even when static.

Useful motifs:

- route lines
- lane markers
- streak trails
- ladder rails
- radial progress arcs

### 2. Pressure

Revision should feel alive, not flat.

Useful cues:

- warm threat tones for weak or neglected content
- dense, high-contrast overlays in game moments
- countdowns and build-up states that create anticipation

### 3. Control

Even when dramatic, the UI should stay legible.

Useful cues:

- sharp panel edges or disciplined radius rules
- consistent spacing rhythm
- clear hierarchy between base, elevated, and floating surfaces

## Colour system

The palette should support a dark-first product with custom learner accents.

### Base neutrals

- `coal` - near-black base background
- `graphite` - raised surface background
- `smoke` - muted panels, dividers, inactive fills
- `chalk` - primary text
- `fog` - secondary text

### Functional colour roles

- `accent` - learner-chosen identity colour used for focus, CTA, and active progress
- `glow` - brighter companion to accent for highlights and motion
- `success` - cool green-cyan used for stable mastery and completion
- `warning` - amber used for due soon and medium risk
- `danger` - hot coral-red used for weak cards and neglected sets
- `ice` - cool desaturated blue for calm analytics and secondary data

### Behaviour rules

- Avoid rainbow UI. Most screens should rely on neutrals plus one dominant accent.
- Danger should be reserved for real learning risk, not decorative noise.
- Weak and neglected sets should share a family resemblance, but neglected should read less severe than weak.
- Games may temporarily break the calmer dashboard palette, but the underlying system should still feel consistent.

## Typography

Typography should do a lot of the identity work.

### Pairing direction

- Display face: condensed or high-personality serif/sans for headings
- UI face: clean sans-serif for controls and supporting copy
- Mono face: optional for counters, timers, XP, and analytics moments

### Tone rules

- Headings should feel deliberate and slightly compressed
- Labels and metadata should feel instrument-like
- Body copy should stay minimal and direct
- Over-explaining on screen should be avoided

### Relative use

- Dashboard and deck surfaces: restrained typography contrast
- Flashcards: large, tactile word presentation
- Games: oversized display type for prompts and states
- Stats: more mono and tabular rhythm

## Surface hierarchy

The app should clearly distinguish layers.

### Base layer

- app background
- atmospheric gradients
- subtle grain or texture

### Elevated layer

- cards
- deck tiles
- stat modules
- filter trays

### Floating layer

- modals
- reward toasts
- game overlays
- streak celebrations

### Rules

- Not every panel should look equally important
- Important actions should either be brighter, larger, or more elevated, not all three at once
- Games should often collapse back to base plus floating overlays to reduce clutter

## Shape language

Vocivo should avoid both overly soft blobs and harsh enterprise boxes.

Suggested direction:

- medium radius for cards and controls
- stronger geometry for game HUDs
- pill shapes for filters, streak counters, and progress labels
- rings and rails repeated across the system

## Iconography

Icons should feel fast and functional.

Preferred icon families:

- route, compass, bolt, flame, shield, star, timer, radar, crown

Avoid:

- childish mascots
- overly literal textbook icons
- emoji as a primary system language

Emoji can still appear selectively in playful contexts, but should not carry the brand.

## Motion

Motion should create energy, feedback, and reward.

### Key motion moments

- dashboard entry
- flashcard flip
- achievement unlock
- streak surge
- game countdown
- end-of-run summary reveal

### Motion rules

- movement should mostly rely on transform and opacity
- progress motion should feel smooth and inevitable, not bouncy for the sake of it
- high-pressure states can shake or pulse briefly, but should not become visually noisy
- reduced-motion alternatives should preserve clarity without flattening feedback entirely

## Screen personalities

### Dashboard

Mood:

- command centre
- radar
- calm control with visible energy underneath

Should emphasise:

- streak
- goal ring
- neglected areas
- quickest route into useful practice

### Theme and deck browsing

Mood:

- catalogue of targets
- learner sees breadth and gaps immediately

Should emphasise:

- coverage
- practice heat
- filter combinations
- prebuilt deck identity

### Flashcards

Mood:

- tactile
- premium
- slightly collectible

Should emphasise:

- one-word focus
- confidence actions
- subtle but satisfying transitions

### Stats

Mood:

- signal-rich
- analytical
- honest

Should emphasise:

- trend clarity
- neglected sets
- weak areas
- meaningful comparison over vanity

### Games

Mood:

- immersive
- theatrical
- stripped of unnecessary chrome

Should emphasise:

- prompt clarity
- danger and momentum
- run state
- end-of-run payoff

## Visual anti-patterns

Do not drift into:

- purple gradient plus rounded white cards
- corporate dashboard charts with a language skin
- gamification stickers that feel juvenile
- too many colours active on one screen
- soft, vague hierarchy where everything feels equally clickable

## Quality bar

The interface is on the right track when:

- a screenshot is recognisable as Vocivo even without the logo
- weak and neglected areas stand out in under two seconds
- the dashboard feels motivating before a learner reads any copy
- each game screenshot feels like a different mode of the same brand, not a different app
